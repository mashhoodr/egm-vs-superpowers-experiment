# txmerge Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A stdlib-only CLI `python -m txmerge merge` that merges overlapping bank CSV exports into one deduplicated, transfer-linked, categorised ledger CSV.

**Architecture:** A pipeline of pure stages over a `Transaction` dataclass: read → dedupe → sort → pair transfers → categorise → write. Only `cli.py` touches exit codes; only `cli.py`/`writer.py` write files. Every stage is deterministic (no dict/set iteration order dependence beyond insertion order, no clocks).

**Tech Stack:** Python 3.11+ stdlib (`csv`, `decimal`, `datetime`, `argparse`, `dataclasses`); pytest for tests.

**Spec:** `docs/superpowers/specs/2026-11-02-txmerge-design.md` (read it before starting any task).

## Global Constraints

- Python 3.11+, **standard library only at runtime**; `pytest` allowed for tests.
- Package lives in `txmerge/` at repo root; runs as `python -m txmerge merge --account NAME=PATH [--account NAME=PATH ...] --rules RULES.csv --out LEDGER.csv`.
- Format A header `Date,Description,Debit,Credit,Balance`, date `DD/MM/YYYY`, Debit/Credit positive or blank, may contain thousands separators (`1,250.00`).
- Format B header `Transaction Date,Posting Date,Details,Amount`, dates `YYYY-MM-DD`, Amount signed (negative = spend). Use Transaction Date only.
- Rules file header `pattern,category`.
- Output header exactly `date,account,description,amount,category,transfer_id`; `date` ISO `YYYY-MM-DD`; `amount` signed (outflow negative), 2 decimals; `transfer_id` blank unless the row is in a transfer.
- Exit 0 on success; exit 2 (no output file) on unknown header, missing/unreadable file, bad arguments.
- Money is `decimal.Decimal`, never `float`.
- Pipeline order must hold: read → dedupe → sort → pair transfers → categorise → write. Transfer pairing runs on deduplicated rows.
- Same inputs → byte-identical output.

## Review Focus

1. **CRLF line endings / BOM / stray spaces in the header row** (Excel-saved exports) — header still detected; owned by Task 1 (`test_header_with_bom_crlf_and_spaces`).
2. **Descriptions containing commas or double quotes** — round-trip correctly through the output CSV; owned by Task 5 (`test_description_with_comma_and_quotes_round_trips`).
3. **Amounts without decimals or with separators (`1,250`, `"1,250.5"`)** — become `1250.00` / `1250.50`; owned by Task 1 (`test_format_a_thousands_and_no_decimals`) and Task 5 (`test_format_amount`).
4. **`--account` path containing `=`** (e.g. `cur=/tmp/a=b.csv`) — split on the first `=` only; owned by Task 6 (`test_parse_account_splits_on_first_equals`).
5. **Rules file with BOM, blank lines, or spaces around pattern** — loads cleanly, blank-pattern rows ignored (an empty pattern would otherwise match everything); owned by Task 4 (`test_load_rules_bom_blank_and_spaces`).

`txmerge/readers.py`:
```python
"""Read one bank export (Format A or B) into Transactions."""
import csv
from datetime import date, datetime
from decimal import Decimal, InvalidOperation
from typing import Callable

from txmerge.model import InputError, Transaction

FORMAT_A = ["Date", "Description", "Debit", "Credit", "Balance"]
FORMAT_B = ["Transaction Date", "Posting Date", "Details", "Amount"]


class _BadRow(ValueError):
    pass


def parse_amount(text: str) -> Decimal:
    cleaned = text.strip().replace(",", "")
    try:
        value = Decimal(cleaned)
    except InvalidOperation:
        raise ValueError(f"bad amount {text!r}") from None
    if not value.is_finite():
        raise ValueError(f"bad amount {text!r}")
    return value


def _parse_date(text: str, fmt: str) -> date:
    try:
        return datetime.strptime(text.strip(), fmt).date()
    except ValueError:
        raise _BadRow(f"bad date {text!r}") from None


def _amount(text: str) -> Decimal:
    try:
        return parse_amount(text)
    except ValueError as exc:
        raise _BadRow(str(exc)) from None


def _row_a(row: list[str]) -> tuple[date, Decimal, str]:
    when = _parse_date(row[0], "%d/%m/%Y")
    debit, credit = row[2].strip(), row[3].strip()
    if not debit and not credit:
        raise _BadRow("neither Debit nor Credit set")
    if debit and credit:
        raise _BadRow("both Debit and Credit set")
    value = _amount(debit or credit)
    if value < 0:
        raise _BadRow(f"bad amount {(debit or credit)!r}: must be positive")
    return when, (-value if debit else value), row[1].strip()


def _row_b(row: list[str]) -> tuple[date, Decimal, str]:
    when = _parse_date(row[0], "%Y-%m-%d")
    return when, _amount(row[3]), row[2].strip()


def read_export(account: str, path: str, arg_index: int,
                warn: Callable[[str], None]) -> list[Transaction]:
    try:
        with open(path, newline="", encoding="utf-8-sig") as fh:
            return _read(fh, account, path, arg_index, warn)
    except OSError as exc:
        raise InputError(f"cannot read {path}: {exc.strerror or exc}") from None
    except UnicodeDecodeError:
        raise InputError(f"cannot read {path}: not UTF-8 text") from None


def _read(fh, account, path, arg_index, warn) -> list[Transaction]:
    reader = csv.reader(fh)
    header = next(reader, None)
    cells = [c.strip() for c in header] if header else []
    if cells == FORMAT_A:
        parse, width = _row_a, len(FORMAT_A)
    elif cells == FORMAT_B:
        parse, width = _row_b, len(FORMAT_B)
    else:
        raise InputError(f"{path}: unrecognised header {header!r}")

    rows: list[Transaction] = []
    for row in reader:
        line = reader.line_num
        if not any(cell.strip() for cell in row):
            continue
        try:
            if len(row) != width:
                raise _BadRow(f"expected {width} fields, got {len(row)}")
            when, amount, desc = parse(row)
        except _BadRow as exc:
            warn(f"WARNING: {path}:{line}: {exc}")
            continue
        rows.append(Transaction(account, when, amount, desc, (arg_index, line)))
    return rows
```

`txmerge/dedupe.py`:
```python
"""Collapse duplicates caused by overlapping exports of the same account."""
from collections import Counter
from dataclasses import replace

from txmerge.model import Transaction


def normalise(description: str) -> str:
    return " ".join(description.split()).casefold()


def _key(t: Transaction):
    # Decimal("-3.5") == Decimal("-3.50") and they hash equal, so scale is ignored.
    return (t.account, t.date, t.amount, normalise(t.description))


def dedupe(rows: list[Transaction]) -> list[Transaction]:
    ordered = sorted(rows, key=lambda r: r.source)
    per_file: Counter = Counter()
    first_text: dict = {}
    for r in ordered:
        k = _key(r)
        per_file[(k, r.source[0])] += 1
        first_text.setdefault(k, r.description)
    keep: Counter = Counter()
    for (k, _file), n in per_file.items():
        keep[k] = max(keep[k], n)

    out: list[Transaction] = []
    taken: Counter = Counter()
    for r in ordered:
        k = _key(r)
        if taken[k] < keep[k]:
            taken[k] += 1
            out.append(replace(r, description=first_text[k]))
    return out
```

  - `txmerge.transfers.pair_transfers(ordered: list[Transaction]) -> list[str]` — same length as input; `"T0001"`-style id or `""` per row. Input must already be in output order.

Rule (spec "Transfer pairing"): outflow (<0) pairs with inflow (>0) of equal absolute amount, different account, `abs(day diff) <= 3`. Walk outflows in output order; choose unpaired candidate with smallest day diff; tie → earliest in output order. Ids `T{n:04d}` in pair-formation order.

```python
"""Output ordering and transfer pairing between the user's own accounts."""
from collections import defaultdict

from txmerge.model import Transaction

WINDOW_DAYS = 3


def sort_key(t: Transaction):
    return (t.date, t.account, t.source)


def order(rows: list[Transaction]) -> list[Transaction]:
    return sorted(rows, key=sort_key)


def pair_transfers(ordered: list[Transaction]) -> list[str]:
    ids = [""] * len(ordered)
    inflows_by_amount: dict = defaultdict(list)  # amount -> [index, ...] in output order
    for j, row in enumerate(ordered):
        if row.amount > 0:
            inflows_by_amount[row.amount].append(j)

    next_id = 1
    for i, out in enumerate(ordered):
        if out.amount >= 0:
            continue
        best = None  # (day_diff, index)
        for j in inflows_by_amount.get(-out.amount, ()):
            cand = ordered[j]
            if ids[j] or cand.account == out.account:
                continue
            diff = abs((cand.date - out.date).days)
            if diff <= WINDOW_DAYS and (best is None or diff < best[0]):
                best = (diff, j)
        if best is not None:
            tid = f"T{next_id:04d}"
            ids[i] = ids[best[1]] = tid
            next_id += 1
    return ids
```

```python
"""Rule-based categorisation: case-insensitive substring, first match wins."""
import csv

from txmerge.model import InputError

UNCATEGORISED = "Uncategorised"
TRANSFER = "Transfer"


def load_rules(path: str) -> list[tuple[str, str]]:
    try:
        with open(path, newline="", encoding="utf-8-sig") as fh:
            reader = csv.reader(fh)
            header = [c.strip() for c in next(reader, [])]
            if header != ["pattern", "category"]:
                raise InputError(f"{path}: rules header must be 'pattern,category'")
            rules = []
            for row in reader:
                if len(row) < 2 or not row[0].strip():
                    continue
                rules.append((row[0].strip(), row[1].strip()))
            return rules
    except OSError as exc:
        raise InputError(f"cannot read {path}: {exc.strerror or exc}") from None
    except UnicodeDecodeError:
        raise InputError(f"cannot read {path}: not UTF-8 text") from None


def categorise(description: str, rules: list[tuple[str, str]]) -> str:
    text = description.casefold()
    for pattern, category in rules:
        if pattern.casefold() in text:
            return category
    return UNCATEGORISED
```

```python
"""Write the merged ledger CSV."""
import csv
from decimal import ROUND_HALF_UP, Decimal

from txmerge.model import LedgerEntry

HEADER = ["date", "account", "description", "amount", "category", "transfer_id"]
_CENT = Decimal("0.01")


def format_amount(amount: Decimal) -> str:
    q = amount.quantize(_CENT, rounding=ROUND_HALF_UP)
    if q == 0:
        q = Decimal("0.00")
    return f"{q:f}"


def write_ledger(path: str, entries: list[LedgerEntry]) -> None:
    with open(path, "w", newline="", encoding="utf-8") as fh:
        writer = csv.writer(fh, lineterminator="\n")
        writer.writerow(HEADER)
        for e in entries:
            t = e.txn
            writer.writerow([t.date.isoformat(), t.account, t.description,
                             format_amount(t.amount), e.category, e.transfer_id])
```

```python
"""Command-line entry point: python -m txmerge merge ..."""
import argparse
import sys

from txmerge.categorise import TRANSFER, categorise, load_rules
from txmerge.dedupe import dedupe
from txmerge.model import InputError, LedgerEntry
from txmerge.readers import read_export
from txmerge.transfers import order, pair_transfers
from txmerge.writer import write_ledger


def parse_account(value: str) -> tuple[str, str]:
    name, sep, path = value.partition("=")
    if not sep or not name.strip() or not path:
        raise argparse.ArgumentTypeError(f"expected NAME=PATH, got {value!r}")
    return name.strip(), path


def build_ledger(accounts: list[tuple[str, str]], rules_path: str, warn) -> list[LedgerEntry]:
    # Pipeline order is load-bearing: read -> dedupe -> sort -> pair -> categorise.
    rows = []
    for index, (name, path) in enumerate(accounts):
        rows.extend(read_export(name, path, index, warn))
    rules = load_rules(rules_path)
    ordered = order(dedupe(rows))
    ids = pair_transfers(ordered)
    return [LedgerEntry(t, TRANSFER if tid else categorise(t.description, rules), tid)
            for t, tid in zip(ordered, ids)]


def _parser() -> argparse.ArgumentParser:
    parser = argparse.ArgumentParser(prog="txmerge")
    sub = parser.add_subparsers(dest="command", required=True)
    merge = sub.add_parser("merge", help="merge bank exports into one ledger")
    merge.add_argument("--account", action="append", required=True, type=parse_account,
                       metavar="NAME=PATH")
    merge.add_argument("--rules", required=True)
    merge.add_argument("--out", required=True)
    return parser


def main(argv: list[str] | None = None) -> int:
    args = _parser().parse_args(argv)

    def warn(message: str) -> None:
        print(message, file=sys.stderr)

    try:
        entries = build_ledger(args.account, args.rules, warn)
        write_ledger(args.out, entries)
    except InputError as exc:
        print(f"error: {exc}", file=sys.stderr)
        return 2
    except OSError as exc:
        print(f"error: cannot write {args.out}: {exc.strerror or exc}", file=sys.stderr)
        return 2
    return 0
```
